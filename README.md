# Shop Welds

The welder's tablet app for Ridgeway Aluminum (Ian / Chris).
Live at https://mlieuwen-code.github.io/shop-welds/

It shares the Cut Sheets App backend (Apps Script) with Shop Cuts, so jobs, ticks and sign-offs flow between the two apps.
